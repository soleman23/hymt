# HYMT Keyword & Topic Map

Target query clusters mapped to URLs. Priority order for content work after
launch.

---

## 1. The competitive reality, stated plainly

Head terms in this space are not available to a single-advisor site, and
pretending otherwise wastes the entire content budget. The SERPs for
"luxury travel advisor," "best safari travel agent," "how to book a safari" are
held by:

- **Consortium directories** — `virtuoso.com/advisors` and its agency search
  rank for the advisor terms themselves. If HYMT is a Virtuoso, Signature or
  Serandipians member, the win is a *complete profile on their domain*, not a
  competing page on ours.
- **Publisher lists** — Condé Nast Traveler's "Top Travel Specialists" and the
  derivative posts every consortium writes about it. Closed process, not
  rankable.
- **20-year-old mega-operators** — Micato, Go2Africa, Abercrombie & Kent,
  Alluring Africa for safari; Roadtrips, Golfbreaks, YourGolfTravel for
  Masters and Derby.
- **Forums** — Tripadvisor and Fodor's threads now rank for research-stage
  queries that used to belong to blogs. Reddit in particular is heavily cited by
  AI answer engines.

What *is* available: the long tail where a specific question meets a specific
place or trip type, and nobody has published a straight answer. That is where
this map points.

## 2. Priority clusters

Priority is `P1` (do first, high commercial intent + winnable) through `P3`
(worth doing eventually).

### Cluster A — Cost transparency `P1`

**Why first:** almost no luxury operator publishes numbers. Cost questions are
high-volume, high-intent, and the pages that answer them are exactly what
answer engines quote — a dated number is quotable in a way an adjective is not.

| Query | Intent | Target URL |
|---|---|---|
| how much does a luxury African safari cost per person | Info/Comm | new post: `/travel-journal/what-a-safari-actually-costs/` |
| what a $50k safari gets you that a $15k one doesn't | Info | same |
| do travel advisors charge fees / how much does a travel advisor cost | Info | `/faq/` + new post |
| Antarctica expedition cruise cost per day | Info | new post: `/travel-journal/antarctica-what-it-costs/` |
| what's included in a luxury safari price and what isn't | Info | destination pages (Africa) + post |
| Masters badge and hotel package cost | Comm | `/travel-journal/masters-field-report/` (expand) |
| Kentucky Derby package cost by seating tier | Comm | `/travel-journal/kentucky-derby-field-report/` (expand) |
| cost of a multigenerational family trip for 8 | Info/Comm | `/experiences/multigenerational-travel/` |
| gorilla trekking permit cost Rwanda vs Uganda | Info | `/destinations/rwanda/` |
| French Polynesia overwater villa cost per night | Info | `/destinations/french-polynesia/` |

**Format:** a range, what's inside it, the two or three variables that move it,
a dated "verified as of" line, and a link to whatever authority sets the fixed
costs (permits, park fees, tournament pricing).

### Cluster D — "What it's actually like" `P1`

**Why:** this is the E-E-A-T moat. Google explicitly rewards *"expertise that
comes from having actually used a product or service, or visiting a place,"* and
nobody can copy Mark's actual trips.

| Query | Intent | Target URL |
|---|---|---|
| what a private guided safari is actually like day to day | Experiential | new post |
| how rough is the Drake Passage really | Experiential | `/destinations/antarctica/` |
| what the Masters is actually like to attend | Experiential | `/travel-journal/masters-field-report/` |
| what staying at [named camp/lodge] is really like | Experiential | field-report posts |
| Glacier Express — worth the money? | Experiential | `/travel-journal/glacier-express-field-report/` |
| heli-skiing for a first-timer | Experiential | `/travel-journal/heli-ski-field-report/` |
| Amanjiwo — honest assessment | Experiential | `/travel-journal/amanjiwo-field-report/` |
| Singita Grumeti — what you're paying for | Experiential | `/travel-journal/singita-grumeti-field-report/` |

**Add 4–6 more field reports per year — but only from trips that happened.**
The format is the most defensible content type on the site precisely because
it is first-hand, which is also why it is the most damaging when it is not.
The six existing ones were written without a trip behind them; two claimed a
dated stay and were reframed as property assessments in e6b13f3 and its
follow-up. Do not commission another until Mark has a trip to write up.

## 4. Measuring this

There is no reliable reporting surface for AI citation. Anyone selling one is
extrapolating. The honest method:

**Monthly**, ask ChatGPT, Claude, Perplexity and Google AI Mode roughly ten
queries drawn from Clusters A–D, in a fresh session with no memory, and record:

| Field | |
|---|---|
| Date | |
| Engine | |
| Query | |
| Was hymtravel.com cited? | Y/N |
| If not, who was? | |
| Answer quality on our topic | 1–5 |

Keep it in `docs/seo/ai-visibility-log.md`. Six months of this is worth more
than any tool, because it tells you which *specific* competitor page is being
quoted and therefore what yours needs to beat.

**Alongside**, from GSC: impressions and average position per cluster, using the
target URLs above as the page filter. Impressions moving with no click movement
means the content is right and the title/description is not.
